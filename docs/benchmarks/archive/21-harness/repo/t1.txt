What it decides:

The `max_active` function in `sched.rs` calculates the maximum number of
requests that can run simultaneously based on GPU memory constraints.
Specifically:

- It allows 1 request for all models except Qwen3.5 on CUDA
- For Qwen3.5 on CUDA, it computes:
  * The free GPU memory after loading the model
  * The memory required for recurrent state (KV cache)
  * The safety slack (`GPU_SLACK_BYTES`)
  * Divides the remaining free memory by the state bytes per request
  * Returns the number of copies that fit, minus 1 (for the idle session),
    clamped between 1 and `MAX_ACTIVE`

In essence, it decides how many concurrent requests the GPU can support while
keeping enough memory for activations and recurrent state.
